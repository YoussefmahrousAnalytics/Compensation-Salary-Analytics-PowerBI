# Compensation & Salary Analytics Dashboard – Power BI

## Project Overview

An interactive Power BI dashboard designed to analyze employee compensation and salary data across departments, factories, and job levels.

The dashboard provides insights into base salary, overtime pay, bonuses, allowances, total compensation, and headcount.

## Tools & Skills

- Power BI
- Power Query
- Data Modeling
- DAX
- Interactive Dashboards
- HR & Compensation Analytics

## Dashboard Pages

### Page 1 – Compensation & Salary Analytics Dashboard

- KPI Cards
- Year, Department, and Factory Slicers
- Salary and Compensation Analysis

### Page 2 – Salary Analysis

- Detailed Salary Analysis
- Compensation Analysis by Department, Factory, and Job Level
- Key Business Insights

## Key Business Insights

- Production has the highest Total Base Salary among departments.
- Factory 01 has the highest Total Base Salary among factories.
- Sales has the highest Average Total Compensation among departments.
- Manager has the highest Average Base Salary among job levels.
- Supervisor has the highest Total Compensation among job levels.

## Project Highlights

- Built an interactive compensation dashboard using Power BI.
- Created DAX measures to calculate salary and compensation KPIs.
- Analyzed compensation across departments, factories, and job levels.
- Added interactive Year, Department, and Factory slicers.
- Designed a two-page dashboard for high-level and detailed salary analysis.
